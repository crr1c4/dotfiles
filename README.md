# Dotfiles

## 🧠 Neovim Config (v0.11+)

A modern and modular Neovim configuration focused on speed, clarity, and productivity. Built in Lua and designed to run smoothly on **Neovim v0.11.0+**.

> ⚠️ Requires Neovim 0.11 or newer.

### 📦 Key Plugins

- [neo-tree.nvim](https://github.com/nvim-neo-tree/neo-tree.nvim) – Modern file explorer
- [mason.nvim](https://github.com/williamboman/mason.nvim) – LSP/DAP/tool installer
- [blink.cmp](https://github.com/Saghen/blink.cmp) – Completion engine
- [lualine.nvim](https://github.com/nvim-lualine/lualine.nvim) – Custom statusline
- [noice.nvim](https://github.com/folke/noice.nvim) – Better command-line UI
- [telescope.nvim](https://github.com/nvim-telescope/telescope.nvim) – Fast fuzzy finder
- [todo-comments.nvim](https://github.com/folke/todo-comments.nvim) – Highlight TODOs

### 🎨 Available Themes

- Kanagawa
- Moonlight
- Oh-lucy
- Tokyonight
